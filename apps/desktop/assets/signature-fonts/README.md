# Bundled handwriting fonts

Downloaded 20 November 2026 from Google Fonts upstream (unmodified binaries):
- https://github.com/google/fonts/tree/main/ofl/caveat
- https://github.com/google/fonts/tree/main/ofl/dancingscript

Caveat and Dancing Script are distributed under SIL Open Font License 1.1.
The corresponding copyright and OFL notices are included next to each font.
Fonts are embedded for offline rasterization; no OS font installation is needed.
