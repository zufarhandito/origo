# Bundled text annotation font

Copied unmodified from the vendored upstream Zed / GPUI dependency checkout
(`assets/fonts/ibm-plex-sans`, IBM Plex Sans Regular):
- `IBMPlexSans-Regular.ttf`
- `IBMPlexSans-OFL.txt`

IBM Plex Sans is distributed under SIL Open Font License 1.1.
The font is embedded for deterministic offline rasterization of passive text
annotations (text/date/name) in the viewer, PNG export, printing, and PDF
appearance streams; no OS font installation is needed.
